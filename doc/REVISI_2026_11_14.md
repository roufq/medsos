# Revisi Postter — 14 November 2026

Persetujuan: index adalah halaman perkenalan sebelum login; logo memakai PNG yang
dikirim; auth tambahan dan impor akun (poin 19) ditunda. Iklan berbentuk postingan
biasa dengan penanda iklan. Profil/konten publik dapat dibaca tanpa login, tetapi
akun privat dan postingan khusus pengikut tidak diubah menjadi publik.

## Perubahan

- Index responsif pada `/`, dengan login/daftar/jelajahi; pengguna yang sudah login
  tetap membuka feed. `/explore` menyediakan feed publik untuk pengunjung.
- Wordmark `postter.us` dan PNG asli, tema hitam/putih melalui CSS. Spinner awal
  memakai indikator radial. Tagline dan judul halaman sesuai area aplikasi.
- Navigasi mobile: Home, Explore, Shop, New Post, Notification, Profil. Header
  aplikasi pada mobile hanya menampilkan pencarian. Search desktop diperlebar
  dan navigasi didekatkan. Gambar tunggal menampilkan rasio aslinya secara penuh.
- Hashtag dari deskripsi dan kolom tambahan dapat diubah/dihapus pada editor.
  Hashtag ditampilkan biru di atas media, tanpa mengulang tag yang sudah ada di
  deskripsi. Metadata link otomatis mengisi judul/deskripsi yang masih kosong
  atau belum disunting; hasil tetap dapat diedit. Gambar artikel tampil di post
  tautan dari hasil pemrosesan preview yang sudah ada.
- Profil menjadi `/{username}`. URL lama tetap dapat dibuka dan diarahkan ke URL
  canonical oleh SPA. Nama yang bertabrakan dengan route aplikasi dilindungi;
  username lama yang berbenturan tetap memakai `/profile/{username}`.
- Halaman profil/post publik, metadata HTML/OpenGraph, robots.txt, dan sitemap.xml
  disediakan. Post followers-only dan akun privat tidak dimasukkan ke sitemap.
  Indeks mesin pencari tetap bergantung pada proses crawling mesin pencari.
- Kuota paket default nonaktif untuk semua perangkat. Admin dapat mengaktifkan
  kembali melalui Administrator → Pengaturan. Pricing disembunyikan selama
  kuota nonaktif. Validasi keamanan file dan persyaratan isi postingan tetap ada.
- Admin memakai header/sidebar/tema yang sama dengan pengguna. Ada pengelolaan
  pengguna, moderasi konten/laporan, pencarian dan pagination konten, aktivitas
  terbaru, serta pengaturan kuota. Hapus akun menonaktifkan dan menganonimkan
  tampilan akun, menyembunyikan kontennya, serta mencabut sesi; data audit disimpan.
- Centang biru manual admin terpisah dari langganan dan tidak hilang ketika
  langganan berakhir. Pembayaran berbayar tidak dibuat pada revisi ini; teks
  metode pembayaran dari klien tidak dianggap bukti pembayaran.
- Admin dapat membuat postingan iklan atau menandai postingan publik yang sudah
  ada sebagai iklan, serta menghentikan status iklan. Tidak ada eksekusi kode
  iklan dari teks postingan. Iklan memakai urutan feed biasa.

## Data dan rilis

Startup AutoMigrate menambahkan `platform_settings`, `user_activities`,
`users.admin_verified`, dan `posts.is_sponsored`. Cadangkan database sebelum
deploy. Riwayat aktivitas baru dicatat setelah versi ini diaktifkan; tidak
merekonstruksi aktivitas lama. Log mencatat metode dan path tindakan berhasil,
tanpa body request atau isi pesan pribadi. Sesi terbaru dibaca dari login_sessions.

Pengaturan platform tersimpan sebagai satu record ID 1. Jika belum ada record,
upload bebas kuota paket. Jika query konfigurasi gagal, proses posting gagal
dengan pesan kesalahan; tidak diam-diam mengabaikan batas yang mungkin aktif.

Halaman publik hanya menyediakan pembacaan. Menulis, mengikuti, berkomentar,
dan moderasi tetap membutuhkan autentikasi dan otorisasi yang sesuai.

## Verifikasi

Perbaikan Beranda kosong: backend lokal lama membalas `/api/v1/public/posts`
dengan HTML fallback SPA. Feed sekarang memvalidasi respons array dan Beranda
menampilkan kesalahan beserta tombol coba lagi. Rute API yang tidak ditemukan
mengembalikan JSON 404. Backend lokal dibangun ulang dan diuji menggunakan data
lokal sebenarnya: API mengembalikan 10 entri, feed merender 9 kartu setelah
deduplikasi repost. Binary sebelumnya dicadangkan di folder tmp.

Navigasi pengunjung: Beranda publik tersedia di `/home`, sedangkan `/` tetap
menjadi halaman perkenalan sebelum login. Sidebar dan navigasi mobile tersedia
di Beranda, Explore, Shop, detail postingan, dan profil publik. Shop memakai
endpoint feed publik untuk pengunjung, termasuk pemuatan halaman berikutnya.
Buat postingan, Koleksi, Profil sendiri, dan pengaturan tetap meminta login.
Nama rute `home` dicadangkan; akun lama bernama home memakai `/profile/home`.
Alur ini diuji di browser tanpa sesi pada desktop dan HP dengan data demo;
tes MySQL memeriksa bahwa Shop publik tidak membocorkan konten privat.

Explore tersedia di `/explore` untuk pengunjung dan pengguna masuk. Kartu memakai
postingan publik dari akun aktif yang tidak privat; blokir antarpengguna tetap
berlaku saat masuk. Filter kategori memakai hashtag yang sudah ada, termasuk
padanan Indonesia/Inggris seperti desain/design dan fotografi/photography/foto.
Tersedia pencarian, urutan terbaru/terpopuler, grid/daftar, dan pagination.
Simpan dan suka membutuhkan login. Tautan Explore ada di samping logo landing.
Tampilan diuji pada desktop 1536px dan HP 390px menggunakan data demo terisolasi.
Tes repository memeriksa privasi, blokir, hashtag, pencarian, urutan, pagination,
serta status suka/simpan pada database MySQL fixture.

```powershell
$env:REVISION_TEST_MYSQL_DSN='root@tcp(127.0.0.1:3317)/?parseTime=true'
go test ./app/repositories ./app/http/controllers ./app/services ./app/models ./app/http/middleware ./routes
```

Tes MySQL membuat dan menghapus database fixture sendiri, tidak memakai database
pengguna. Tanpa variabel tersebut, tes integrasi dilewati. Tes metadata dan
username tetap berjalan. Build frontend: `npm run build` di folder frontend.

Pengujian browser lokal menggunakan data demo terisolasi: index terang/gelap,
desktop/mobile, navigasi, URL profil publik, metadata link, edit hashtag, dan
kontrol admin. Belum diterapkan ke AWS pada revisi ini. Poin auth tambahan dan
impor akun tetap ditunda sesuai arahan.
